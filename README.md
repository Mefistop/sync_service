# Сервис синхронизации файлов

Это приложение на Python, предназначенное для синхронизации файлов между локальной директорией на компьютере пользователя и облачным хранилищем. Приложение периодически сканирует указанную локальную папку, отслеживает изменения (новые файлы, измененные файлы или удаленные файлы) и обновляет облачное хранилище соответственно.

## Описание функционала

### Синхронизация файлов
- Отслеживает изменения в локальной директории и синхронизирует их с облачным хранилищем
- Загружает новые файлы в облачное хранилище
- Обновляет измененные файлы в облачном хранилище
- Удаляет файлы из облачного хранилища, если они были удалены локально

### Периодическая синхронизация
- Выполняет синхронизацию через заданный интервал времени (в секундах)

### Конфигурируемые параметры
- Настройки осуществляются через файл `config.py`

## Требования

## Настройка

Приложение настраивается через файл .env. Пример файла: 

[DEFAULT]
```
    LOCAL_PATH = /path/to/local/directory
    REMOTE_FOLDER_NAME = /cloud/folder
    TOKEN = your_cloud_token
    INTERVAL_SECONDS = 300
    LOG_PATH = /path/to/logfile.log
```
```
    LOCAL_PATH: Путь к локальной директории для синхронизации.
    REMOTE_FOLDER_NAME: Имя папки в облачном хранилище.
    TOKEN: Токен доступа к облачному хранилищу.
    INTERVAL_SECONDS: Интервал синхронизации в секундах.
    LOG_PATH: Путь к файлу логов.
```

## Использование

Запустите приложение с помощью команды: 
```bash
  python main.py  
```

При первом запуске выполняется полная синхронизация. Далее синхронизация выполняется с указанным интервалом. 

## Логирование

Все действия и ошибки записываются в файл логов, указанный в LOG_PATH. Пример записи: 
```
syn_service: sync_engine.py  2025-05-12 22:05:66 INFO Программа синхронизации файлов начинает работу с директорией /home/user/Desktop/.
syn_service: yandex_cloud.py  2025-05-12 22:05:39 INFO Файл 'photo_2025-05-05_21-32-19.jpg' успешно записан.
syn_service: sync_engine.py  2025-05-12 22:05:39 INFO Отсуствуют измененные локальные файлы для отправки на облако.
syn_service: sync_engine.py  2025-05-12 22:05:39 INFO Отсуствуют файлы из облака, не синхронизированные с локальной директорией.
syn_service: sync_engine.py  2025-05-12 22:05:39 INFO Синхронизация завершена. Ожидаю 5 секунд до следующей итерации.
```
